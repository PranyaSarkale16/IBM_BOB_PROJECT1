# 🏠 House Price Prediction

A full-stack machine learning web application that predicts house prices (in Indian Rupees, Lakhs) based on property features like location, area, BHK, amenities, and more.

- **Backend**: Flask REST API
- **Frontend**: Streamlit
- **ML Model**: XGBoost Regression (scikit-learn pipeline)
- **Dataset**: [`housing_price_dataset.csv`](housing_price_dataset.csv) — 50,000 Indian residential property listings across Bangalore, Delhi, Hyderabad, and Mumbai (26 features — area, BHK, floor, furnishing, amenities, proximity, and more)

## 2. Dataset

**File:** `housing_price_dataset.csv`  
**Records:** 50,000 Indian residential properties  
**Target variable:** `price_in_lakhs`

| Feature Group | Features |
|---------------|---------|
| Location | city, locality, locality_tier |
| Property | property_type, bhk, bathrooms, balconies |
| Area | built_up_area, carpet_area |
| Floor | floor_number, total_floors, floor_category |
| Condition | facing, furnishing_status, property_age, transaction_type |
| Amenities | gym_available, swimming_pool, power_backup, lift_available |
| Financial | parking_spaces, maintenance_fee_monthly |
| Proximity | distance_to_city_center_km, distance_to_metro_km |
| Neighbourhood | nearby_schools, nearby_hospitals, security_score |

**Cities covered:** Bangalore, Delhi, Hyderabad, Mumbai

## 3. How to Run

### Step 1 — Install dependencies
```bash
pip install -r requirements.txt
```

---

### Option A — Single-file app (recommended, no Flask needed)
```bash
streamlit run house_price_prediction_code.py
```
Opens at: `http://localhost:8501`

> The model trains **automatically on first launch** if `models/xgb_pipeline.pkl` is not found.

---

### Option B — Full Flask + Streamlit setup (3 steps)

**Step 1 — Train the model (run once)**
```bash
python train_model.py
```

**Step 2 — Start Flask API (Terminal 1)**
```bash
python app.py
```
Runs at: `http://localhost:5000`

**Step 3 — Start Streamlit frontend (Terminal 2)**
```bash
streamlit run streamlit_app.py
```
Opens at: `http://localhost:8501`
